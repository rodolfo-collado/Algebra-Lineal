Operaciones: A ∪ B, A ∩ B, A ∖ B, complemento ∁(A, U) con A incluido en el universo explícito U y cardinalidad |A|. Primero se resuelve ∩; después ∪ ∖, de izquierda a derecha. Usa paréntesis para agrupar.

Puedes comparar resultados con ∈ ∉ ⊆ ⊂ = ≠: |A ∩ B| = 2. La pertenencia compara elementos completos; ⊂ exige inclusión y conjuntos distintos.

Potencia: potencia(A). Producto: A × B (prioridad mayor que ∩). Par ordenado: par(1, 2). Intervalo: intervalo(-inf, 2, abierto, cerrado); usa abierto/cerrado para ambos extremos. Los infinitos siempre son abiertos.
