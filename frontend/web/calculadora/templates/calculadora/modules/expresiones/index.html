Por ejemplo A + B, 2A - B, AB, Ax, A(B + C) o Aᵀ (también A^T).

{% disclosure titulo="Cómo se escribe" nivel=4 clase="disclosure-help" %}
  • 2A, AB y A(B + C) multiplican sin escribir *. Si un texto admite más de una lectura, como AB cuando también existe un operando llamado AB, escribe A*B.
  • La traspuesta va después de lo que traspone: Aᵀ o A^T. ABᵀ es A por Bᵀ; para trasponer el producto escribe (AB)ᵀ. ^ no calcula potencias ni inversas.
  • En cada nivel se opera de izquierda a derecha: A - B - C es (A - B) - C y ABC es (AB)C.
  • Escribe fracciones como 1/2, decimales como 0.5 y negativos con -.
  • Un solo = compara dos expresiones con valores, como A(B + C) = AB + AC; no resuelve ecuaciones. Para hallar x en Ax = b usa la herramienta Resolver Ax = b.
  • Tipos simbólicos: con una matriz desconocida A, un vector simbólico x y un vector lineal b, Ax = b determina A comparando coeficientes.
